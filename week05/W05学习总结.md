# W05｜数组与字符串

**学习主题：** C++17 一维与二维数组、字符数组、`std::string`、`std::vector`、基础对数直觉

## 一、核心知识

- 掌握原生数组的初始化、下标访问、遍历与修改；使用 `sizeof(arr) / sizeof(arr[0])` 在数组本身仍可见的作用域内计算元素数。
- 能使用循环求和、平均值、最大值和最小值；求最大值时以 `arr[0]` 初始化，循环从下标 1 开始，适用于全负数数组（前提是数组非空）。
- 理解数组传入函数时通常退化为指针，因此需另外传入长度；`const int arr[]` 防止通过该参数修改元素。
- 掌握二维数组的 `arr[i][j]` 访问、嵌套循环遍历、按行统计和函数参数 `const int arr[][3]`。
- 区分 C 风格字符串和 `std::string`：`char a[] = "cat"` 的数组长度为 4（含 `\0`），而 `std::string("cat").size()` 为 3；`std::string` 也能提供以 `\0` 结尾的字符序列。
- 使用 `getline` 读取含空格的整行输入；了解 ASCII 英文字母大小写转换及 UTF-8 的字节概念：UTF-8 下“中文”占 6 字节，`text[0]` 不代表完整汉字。
- 掌握 `std::vector` 的初始化、`push_back()`、`size()`、`reserve()`；理解 `reserve()` 改变容量而不增加可访问元素数。
- 初步理解以 2 为底的对数与反复折半：数据规模翻倍，折半次数增加 1。

独立编写 `find_max(const int arr[], int len)`：以首元素初始化最大值，从第二个元素开始比较；正确解释不能将初始最大值固定为 0（全负数数组会出错）。

**错题与补缺：**

1. `std::string::size()` 不计额外的字符串终止符，不等于“`std::string` 没有 `\0`”；应区分内容长度与底层字符序列的终止符。
2. UTF-8 中一个汉字通常由多个字节编码；`std::string::size()` 返回字节数，按下标访问得到的是单个字节，不是完整 Unicode 字符。
