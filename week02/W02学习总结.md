# W02｜C++ 基本语法

**学习状态：** 知识验收通过（19/20，95%）  
**学习主题：** 变量、数据类型、运算符、输入输出、整数除法与类型转换  
**开发环境：** Ubuntu 24.04、g++、C++17

## 一、核心知识

- 使用 `int` 保存整数，使用 `double` 保存可带小数的数值。
- 掌握 `std::cin` 输入、`std::cout` 输出及基本算术运算符。
- 理解运算符优先级：`*`、`/` 优先于 `+`、`-`，括号可改变计算顺序。
- 整数除法向零截断；需要浮点除法时，可使用 `3.0` 或 `static_cast<double>(...)` 在运算前转换类型。
- 明白先进行整数除法、再将结果赋给 `double`，无法恢复已舍弃的小数部分。


## 二、验收与复盘


- **易错点：** 整数除法是“向零截断”，不等同于“向下取整”；。
