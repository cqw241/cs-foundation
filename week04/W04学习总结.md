# W04｜函数与第一次阶段测评

**学习主题：** C++17 函数、变量作用域、集合与函数映射

## 一、核心知识

- 掌握函数定义、调用、形参与实参、`return` 返回值及 `bool` 返回类型。
- 理解值传递：形参是独立变量，修改形参不影响实参。
- 理解局部变量、代码块作用域及名称遮蔽。
- 理解集合与函数映射：每个输入对应唯一输出，不同输入可以对应相同输出。
- 掌握边界测试；素数判断由检查到 `n - 1` 优化为 `i <= n / i`，避免乘法溢出。

## 二、实践成果

- `increase()`：验证值传递与内外层同名变量。
- `is_prime()`：完成素数判断和平方根优化；
- `sum_odd()`、`count_primes()`：完成综合编程；
